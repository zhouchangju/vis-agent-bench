# Macro Map 3D 因子关系场景

## 背景

Macro Map 用于帮助投资研究用户理解宏观因子之间的影响关系。我们需要从零开发一个可嵌入网页的 3D 关系场景，让用户既能观察全局结构，也能围绕某个因子查看局部关系。

输入数据包含因子及有向关系。因子具有中英文名称、类别、核心/外围标识和重要性权重；关系具有正向、负向或未知类型。

## 交付

交付一个可运行网页、一个可复用的场景组件以及必要的测试和说明。业务页面需要能够：

- 传入数据、主题、语言、视图模式和可见区域偏移；
- 接收节点和关系的选择事件；
- 查询必要的性能统计。

## P0：业务闭环

- 对完整数据使用稳定的双层球面布局，核心因子在内层、外围因子在外层；
- 节点大小表达重要性，并限制极端值影响；
- 通过节点、标签、背景、内层球体和深度衰减形成明确空间层次；
- 正向、负向、未知关系有稳定视觉编码，有向关系可识别；
- 支持鼠标和触控旋转、缩放、悬停、节点选择和取消；
- 默认缓慢自动旋转，用户操作和悬停时按合理规则暂停；
- 选中节点后突出中心、一跳节点及关系，弱化无关内容；
- 局部态下可以选择关系并定位另一端；
- 区分拖拽和点击，不能在旋转结束时误触；
- 支持长中英文标签和运行时语言切换；
- 在完整数据规模下保持可操作。

## P1：复杂交互

- 支持在 3D 球面局部态与 2D 关系平面之间平滑切换；
- 2D 使用平移操作，3D 使用旋转操作；
- 过渡过程中避免边抖动和错误命中；
- 外部面板占据部分区域时，可按传入偏移修正视觉中心和命中坐标；
- 支持亮色、暗色主题；
- 支持“仅交互时显示关系”和“突出主要关系”两种策略。

## P2：生产化

- 桌面端和移动端采用合理的像素比、标签纹理及几何质量；
- WebGL context lost 后可以恢复，资源不足设备允许降级；
- 避免每帧遍历、重建全部边或创建大量临时对象；
- Resize、切换数据/语言/主题以及重复挂载卸载后无明显资源泄漏；
- 卸载时停止动画并释放纹理、材质、Geometry、Renderer 和监听器；
- 输出 FPS、帧耗时、draw calls、三角形、纹理及可见对象统计。

## 不在范围内

- Header、搜索框、因子集选择器和详情业务内容；
- 真实线上接口和鉴权；
- 对某个现有实现的逐文件复刻。

允许自行选择 Three.js、React Three Fiber 或其他适合的 Web 3D 技术，并在 README 中说明关键取舍和未完成项。
