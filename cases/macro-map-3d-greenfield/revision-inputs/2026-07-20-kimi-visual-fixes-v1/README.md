# Macro Map 3D：Kimi 视觉与交互修订素材包 v1

## 适用范围

本包用于既有 `macro-map-3d-greenfield` Run 的 Revision 子 Run，不用于首轮 Case 评测，也不修改 `scenario/` 中固定的首轮需求。

## 输入内容

- `feedback.md`：原始人工反馈，覆盖标签、Y 轴旋转、环境光、关系筛选、自动旋转、透视、2D 展开、边流光、关系数据语义和右侧面板联动。
- `img/`：问题现状与目标效果截图。保留原始文件名与目录，确保 `feedback.md` 的相对图片链接有效。

`image-20260720142715807.png` 与 `image-20260720142726539.png` 的 SHA-256 相同，是重复图片。运行命令只传入后者，避免无效占用图片上下文。

## 使用约束

- 图片用于理解视觉、交互和验收状态，不得复用其中的业务数据或外部素材。
- 本轮重点是修复已实现功能的正确性与视觉表达；不得以删除筛选、交互、透视或播放能力来换取通过。
- 实际运行时，Revision 子 Run 会复制输入并记录哈希，形成独立、可回溯的证据副本。
