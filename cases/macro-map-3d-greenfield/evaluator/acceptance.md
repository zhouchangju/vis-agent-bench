# 隐藏验收

## 关键失败

- 完整数据无法渲染或主要交互不可用；
- 核心/外围、重要性、关系方向或正负语义映射错误；
- 使用静态图片或删减数据伪装结果；
- 页面卸载后动画循环或 WebGL 资源持续增长。

## P0

- 固定 fixture 下布局确定；
- 内外层半径分布和节点大小排序正确；
- 正/负/未知边及方向可识别；
- 自动旋转、拖拽、缩放、悬停、选择、取消和关系选择通过浏览器测试；
- 拖拽不触发点击，无关节点不错误清空选择；
- 中英文切换及长标签可读；
- 200/800/1481 节点阶梯测试均可操作。

## P1

- 3D/2D 状态、操作模式和过渡正确；
- 画布偏移后视觉中心及命中仍正确；
- 亮暗主题、关系显示策略正确；
- 过渡期间无明显错误边或闪烁。

## P2

- 记录统一测试机 FPS、帧耗时和 Renderer 指标；
- 连续切换数据、主题、语言和 Resize；
- 重复挂载/卸载至少 20 次并比较资源；
-模拟 context lost/restored；
- 检查动画热路径和资源释放。
