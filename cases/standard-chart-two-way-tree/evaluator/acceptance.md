# 隐藏验收

## 关键失败

- 没有接入 StandardChart；
- 左右方向、层级或父子关系错误；
- 固定坐标只适配示例数据；
- 破坏既有构建、测试或主题。

## P0

- 标准、单侧为空、左右不对称、深层、长名称 fixture；
- 中心/左右布局、连线和指标映射正确；
- 展开、收起、选择、再次点击、空白取消及事件回调；
- Resize 后无主要节点裁切，结构保持可理解；
- 缺失值、零值、极端值和重复名称稳定。

## P1

- 分组、主题、Tooltip、强调、选中和禁用状态；
- 数据更新后展开状态和稳定性；
- 窄容器和键盘交互；
- 不同字体和中英文视觉回归。

## P2

- option 类型、默认值、合并和 setOption 行为；
- 单元、交互、视觉测试及文档示例；
- 大树、连续展开和 Resize 性能；
- 全量构建与相关回归。
