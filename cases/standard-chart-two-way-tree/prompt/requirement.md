# StandardChart 产业链双向树

## 背景

研究用户需要围绕一个目标产业查看上游原材料、下游设备或应用及各节点的市场表现。请在现有 StandardChart 仓库中实现一个可复用的产业链双向树组件，而不是在业务页面中手写一次性 SVG。

## P0：业务闭环

- 目标产业位于中心，左侧展示上游，右侧展示下游；
- 支持多级树、左右层级不对称以及任一侧为空；
- 节点展示名称和业务指标，涨跌符合产品金融配色；
- 父子关系清晰，连线不能穿过节点或造成严重遮挡；
- 支持节点选中、再次点击取消、空白取消；
- 支持分支展开/收起，其他分支位置变化应稳定、可理解；
- 对外提供节点点击、展开状态变化等事件；
- 容器 Resize 后自动重排，不裁切中心节点和主要分支；
- 长中英文、重复名称、缺失指标、零值和极端涨跌能够降级展示。

## P1：复杂场景

- 支持业务分组和分组样式；
- 支持根据容器宽度调整层间距、节点宽度和标签策略；
- 数据更新时尽量保持未变化节点的位置和展开状态；
- 支持键盘聚焦和基本可访问性；
- 支持 AInvest PC 明暗主题，并兼容 StandardChart 主题机制；
- Tooltip、强调、选中和禁用状态互不覆盖。

## P2：组件化交付

- 定义清晰、可扩展且类型安全的 option；
- 使用仓库既有扩展机制和生命周期，不绕过 StandardChart；
- 添加完整示例、API 说明、单元测试、交互测试和视觉回归；
- 验证大树、频繁展开、Resize 和重复 setOption；
- 不破坏已有系列、主题和构建产物。

实现前请先阅读仓库结构和现有扩展方式，在说明中记录方案取舍、兼容边界及未完成项。
