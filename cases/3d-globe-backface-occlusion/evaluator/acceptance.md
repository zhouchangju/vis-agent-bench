# 隐藏验收契约：3D 球面视锥背面裁剪与屏幕映射引擎

## P0 核心验收标准（全部必须通过）
1. **正背面遮挡判定（P0_SPHERE_OCCLUSION_FRONT_BACK）**：
   - 相机位于世界原点正前方 $(0, 0, D_{pov})$ 时，球体正表面点位 $(0, 0, R)$ 判定为 `occluded === false`；
   - 球体正背面点位 $(0, 0, -R)$ 判定为 `occluded === true`。
2. **切线边界与地平线临界精度（P0_SPHERE_OCCLUSION_HORIZON_TANGENT）**：
   - 相机到球心距离 $D_{pov} = 200$，球体半径 $R = 100$ 时，地平线切面 Z 坐标为 $Z_{horizon} = R^2 / D_{pov} = 50$；
   - 处于切线视界前方的点（$Z > 50$）必须判定为可视，处于切线视界后方的点（$Z < 50$）必须判定为遮挡。
3. **相机轨道旋转鲁棒性（P0_CAMERA_ROTATION_ORBIT）**：
   - 相机围绕球体旋转至任意非对称轴（如 $(300, 0, 0)$ 或 $(0, 300, 0)$）时，遮挡状态随相机位置实时动态反转（原先背面的点旋转至前方后变为可视，原先可视的点旋转至背面后被剔除）。
4. **透视缩放系数计算（P0_PERSPECTIVE_SCALE）**：
   - 最近可见极点处的缩放系数等于或非常接近 `perspectiveMaxScale`（1.0）；
   - 地平线切点处的缩放系数等于或非常接近 `perspectiveMinScale`（0.4）；
   - 缩放系数随视距 $D_{pos}$ 呈单调递减关系，且数值被严格限制在 $[0.4, 1.0]$ 区间内。
5. **2D 屏幕投影几何精度（P0_SCREEN_PROJECTION_ACCURACY）**：
   - 正对相机视线中心且未被遮挡的球心极点 $(0, 0, R)$ 投影至屏幕时，屏幕像素坐标误差小于 1px（必须严格等于 $(width/2, height/2)$）；
   - 在水平或垂直方向偏移的点位，其屏幕像素偏移量与透视除法推导值一致；
   - 被背面遮挡的点位或位于相机后方的点位，返回 `visible: false`。
6. **批量排版与视口边界处理（P0_BATCH_TOOLTIP_CULLING_AND_LAYOUT）**：
   - `layoutSphereTooltips` 接收包含经纬度的多数据项列表，能够精准识别并剔除全部背向点位；
   - 针对所有可见项赋予正确计算的 `scale` 与屏幕坐标 `(screenX, screenY)`。
