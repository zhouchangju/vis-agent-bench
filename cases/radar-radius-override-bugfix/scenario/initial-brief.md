# 业务 Brief：移动端雷达图半径配置覆盖缺陷

业务方反馈：在移动端图表主题中配置雷达图（`dvRadar`）时，开发人员在图表配置中明确指定了自定义的半径：

```javascript
radar: {
  radius: 50 // 或者 '70%'
}
```

但图表渲染后，用户配置的半径完全没有生效，依然显示为移动端主题默认的超大尺寸；只有在偶然传入复杂对象格式时，配置才偶发保留。

业务方认为这是主题解析模块在处理用户选项与主题默认 Token 时的覆盖判断逻辑有 Bug。

### 当前要求
1. 在开始修改代码前，先阅读 `src/dvRadar.js` 与相关工具函数，在 `requirement-ledger.yaml` 中记录：
   - 导致用户半径配置失效的根因分析；
   - ECharts 雷达图半径支持的合法数据类型；
   - 预期的修复方案与最小自测点。
2. 本阶段为无人值守运行，记录完方案后继续推进修复，确保修复后各类合法入参均能正确保留，且未配置半径时仍能正常回退到主题默认值。
