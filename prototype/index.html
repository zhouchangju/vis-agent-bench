Vis Agent Bench
交互原型

从运行设置、Run 执行状态、证据查看、横向对比到人工评审和领导报告的全流程原型。所有数据均为示例，非真实评测结果。

正式入口 命令行：npm run bench
Run 状态：npm run bench:status
01

运行设置

选择 Case、CLI、模型，配置隔离、预算和证据采集，生成 RunSpec 预览并导出 JSON。

M4 完成 02

Run 状态

查看所有 Run 的执行状态、阶段完成度、墙钟时间、Token 使用，点击展开阶段细节。

New 03

证据查看

按 Run 查看构建/测试、浏览器截图、DOM 快照、Workspace Diff、Attestation 和人工评审状态。

New 04

横向对比

并排对比两个 Run 的时间、Token、费用、Scorecard、Hard Gate 失败和阶段耗时。

New 05

人工评审

对机器证据补充视觉、交互、业务判断和人工修复时间，生成 human-review.json。

M4 完成 06

领导报告

机器聚合报告：能力边界、事实分层、人类时间消耗、管理结论和推荐行动。

M4 完成
ARCHITECTURE NOTE

原型架构

所有 M4 原型页面只消费已有数据，不创建独立执行逻辑。设置页生成 RunSpec，CLI Runner 和网页都调用同一个 Runner Core。

数据流：setup.html 生成 RunSpec JSON → CLI Runner 执行 → .local/runs/ 存储结果 → 报告页面消费已有数据。

示例数据文件：prototype/assets/sample-runs.js（3 个假 Run，被 runs.html / evidence.html / compare.html 共享）。
