# 已选业务复刻 Case：AInvest Market Heatmap

## Case 编号

`CAND-SHOT-HEATMAP-001`

## 来源类型

`observed`

## 真实来源

- 已上线页面：<https://www.ainvest.com/market/heatmap/>
- 页面默认状态包含：Stock、S&P 500、按市值决定面积、按日涨跌幅着色、按 Sector 分组；
- 真实实现位于内部 `ainvest-matrix-react` 的 `widget-heatmap` 包；
- 内部实现只作为需求取证和隐藏验收参考，不提供给参评模型。

这项任务不再是“看一张图写静态页面”，而是“参考已上线产品，使用脱敏稳定数据完成一个可运行的业务级热力图复刻”。

## 模型可见业务需求

为 AInvest 市场页实现一个 Market Heatmap。用户需要在一屏内观察市场板块和标的涨跌，快速切换市场、指数范围、面积指标、颜色指标和分组方式，并能进一步查看板块或标的信息。

提供线上参考页面、脱敏 Mock API、项目脚手架和团队组件库使用说明。交付结果必须由真实数据驱动，不能使用截图贴图或把节点位置写死。

## 完整业务切片

### P0｜必须完成：Stock Heatmap 主闭环

- 支持 S&P 500、NASDAQ 100、NASDAQ Composite、NYSE、All Stocks、Dow Jones 数据源；
- 矩形面积按市值映射，也可切换为等面积；
- 颜色支持日涨跌幅，按连续色阶正确映射正、负、零和极端值；
- 支持按 Sector 分组和不分组；
- 节点至少展示 Symbol、涨跌值，并根据可用面积自动决定信息密度；
- 大节点可展示 Logo，小节点不得因文本溢出破坏布局；
- 悬停显示包含名称、代码、价格、市值和当前颜色指标的 Tooltip；
- 点击板块进入板块，显示返回路径；点击标的触发对外详情事件；
- 容器 Resize 后保持面积比例、分组和当前钻取状态；
- 使用 Mock API，具备 loading、empty、error、retry 四种状态。

### P1｜重要能力：多市场和个性化

- 支持 Stock、ETF、Crypto 三类市场切换；
- ETF 面积按 AUM，按 Asset Class 分组；
- Crypto 支持包含/排除 BTC 的数据源，面积按市值，不要求分组；
- 各市场具有不同的颜色时间范围和颜色深度；
- 支持显示/隐藏 Logo，标题可选 Symbol/Name/None，数值可选当前指标/Price/其他业务指标/None；
- 支持经典红绿、指标专用或单色等颜色方案；
- 支持全屏，退出全屏后恢复原容器状态；
- 当前选择可序列化到 URL 或等价可恢复状态，刷新后主要筛选不丢失。

### P2｜工程与视觉：决定能否用于生产

- 明暗主题均与参考产品保持一致的层级、间距、边框、文本对比和色阶；
- 桌面、窄屏和全屏三种宽度下控件不重叠，必要时收起次要控制；
- 大数据集下交互、缩放、Tooltip 和 Resize 不明显卡顿；
- 快速切换市场或筛选时，过期请求不能覆盖最新状态；
- 切换数据、钻取、Resize 和卸载时不重复绑定事件或泄漏图表实例；
- 交付类型定义、数据转换单测、关键交互测试和视觉回归。

## 隐藏验收重点

- 面积正确性：节点面积排序与 size 指标一致；
- 颜色正确性：边界值、零值、空值、正负值映射；
- 分组正确性：组面积等于子项之和，钻取和返回不丢数据；
- 市场差异：Stock/ETF/Crypto 的数据源、面积、颜色和分组规则不能混用；
- 状态机：快速切换、错误重试、全屏、Resize、URL 恢复；
- 视觉：固定数据和固定 viewport 下的结构及色差；
- 工程：禁止图片占位和硬编码矩形坐标。

## 为什么比原截图题更适合

- 它是已经上线、业务方真实使用的产品；

- 保存线上页面关键状态截图，不依赖线上实时行情做自动断言；
- 记录原团队完成此功能的真实工期、返工点和线上缺陷，作为人效比较基线。
