# ADR-0003：股权关系叙事可视化替代产业链双向树成为主 Case

- 状态：Accepted
- 日期：2026-07-19
- 替代范围：ADR-0001 中 `CAND-SC-001` 的主 Case 身份

## 决策

首期三个主 Case 调整为：

1. Macro Map 3D；
2. 股权关系叙事可视化；
3. AInvest Market Heatmap。

产业链双向树不删除，状态改为 `backup`，用于后续低一档复杂度的组件能力回归。

## 原因

产业链双向树主要考察非标准树布局、主题和基础交互，能够衡量组件开发能力，
但不足以覆盖团队在真实产品开发中最耗时的“需求逐步澄清—视觉微调—复杂状态回归”链路。

股权关系叙事可视化同时包含：

- 组织、人物和数据节点及多种股权边语义；
- 图布局、标签碰撞、跨层边和章节间位置稳定性；
- 节点、边、分组和替换等组合动画；
- 总览、章节、时间线、播放、跳转和恢复状态机；
- 音频、字幕、截图、链接与材料弹窗联动；
- 响应式、容器生命周期、异常数据和回归要求。

这些能力彼此耦合：局部修复可能破坏布局、动画连续性或导航状态，更接近真实开发瓶颈，
也更有机会区分模型是否只是快速生成 Demo，还是能够减少可验收交付中的人工投入。

## 约束

- 模型不可读取 `/Users/leozhou/git/narrative-graph` 或其 Git 历史；
- 正式 fixture 必须脱敏并排除既有实现、测试、示例和唯一类名；
- 完整需求与隐藏验收只供评测端使用，模型按固定阶段逐步获得需求；
- 初期文件隔离结果只用于开发验证，不进入正式排行榜。
